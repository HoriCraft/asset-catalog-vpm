# HoriCraft Asset Catalog VPM

VPM distribution for HoriCraft Asset Catalog. Prerelease versions are provided for installation and operation checks. Product functions require an activation key.

This repository contains compiled packages, distribution metadata and the public landing page. Product source development is managed separately. Unlock keys and buyer-only files must never be committed here.

Listing: https://horicraft.github.io/asset-catalog-vpm/index.json

Local validation and publication staging: [TESTING.md](TESTING.md).
